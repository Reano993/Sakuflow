SAKUFLOW — APLIKASI MANAJEMEN KEUANGAN

ISI APLIKASI
- Catat uang masuk dan uang keluar.
- Setiap transaksi memiliki nominal, keperluan, kategori, tanggal, dan catatan opsional.
- Ringkasan saldo keseluruhan, total masuk, total keluar, dan arus bersih.
- Filter harian, bulanan, dan tahunan.
- Grafik arus kas, riwayat transaksi, pencarian, dan filter kategori/jenis.
- Hapus transaksi dan ekspor riwayat ke CSV.
- Tampilan gelap dan responsif untuk HP maupun desktop.
- PWA/offline shell: dapat dipasang dari browser ketika di-host pada HTTPS atau localhost.

CARA MENJALANKAN
1. Ekstrak folder SakuFlow.
2. Buka index.html di browser untuk penggunaan dasar.
3. Untuk memasang sebagai aplikasi di Android, unggah seluruh isi folder ke hosting HTTPS (misalnya GitHub Pages), buka alamatnya di Chrome, lalu pilih menu "Tambahkan ke layar utama" / "Install app" jika tersedia.

PENYIMPANAN DATA
- Data transaksi disimpan di localStorage browser pada perangkat yang digunakan.
- Data tidak dikirim ke server dan tidak otomatis tersinkron ke perangkat lain.
- Jangan hapus data situs/browser sebelum mengekspor CSV sebagai salinan arsip.
- File CSV dapat dibuka di Excel atau Google Sheets.

CATATAN
Ini adalah aplikasi web sisi-klien, bukan APK Android native dan belum memakai akun/login atau sinkronisasi cloud.
